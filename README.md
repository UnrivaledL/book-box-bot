# Коробка с книгами

Telegram-бот с рекомендациями книг и литературной викториной.
Подбор книг по жанру и настроению, цитаты для угадывания,
информация об авторе, список «Хочу прочитать», XP и лидерборд.

## Стек
- Python 3.11, aiogram 3
- SQLAlchemy (async), SQLite / PostgreSQL
- Google Books API, Open Library
